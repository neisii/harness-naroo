# 오케스트레이션 구성 — 소규모 모드

> 이 하네스를 **여러 세션으로 나눠 돌릴 때** 그 세션들을 어떻게 엮을지 정하는 가이드다. 세션 하나로만 쓰면 이 문서는 필요 없다 — 1단계(per-세션 규율: 청사진→승인→구현→검증·가역성·커밋안전)는 혼자서도 돈다. 설계 근거와 결정 기록은 `design-notes/10-오케스트레이션-구성층.md`.

## 언제 쓰나

- 작업을 **여러 Claude Code 세션**에 나눠 동시에 굴리고 싶을 때.
- 원본 SI의 완전형(전용 `qa-master` 세션·대기 장부·순찰)을 **안 갖춘** 혼자/소규모 환경에서.

## 그림 — 3층 관계

```
사람(결정)  →  게이트웨이 세션(전달·감시)  →  실무자 세션(구현)
```

- **사람** = 모든 게이트(승인)를 쥔다.
- **게이트웨이 세션**(오케스트레이터) = 사람과 실무자 사이의 **통신·감시 창구**. **스스로 결정하지 않는다** — 사람의 승인을 원문 그대로 실무자에 전달하고, 진행을 지켜보다 막히면 사람에게 올린다.
- **실무자 세션**(developer) = 실제 구현. 게이트에서 멈추고, 게이트웨이를 통해 사람의 승인을 기다린다.

핵심 한 줄: **"게이트웨이"는 관문이 아니라 창구다.** 승인은 끝까지 사람에게 있다.

## 소규모 모드 = 없어도 되는 것

완전형이 전제하는 인프라를 **안 갖춰도 된다.** 그 역할은 사람이 메운다.

| 완전형(원본 SI) | 소규모 모드 |
|---|---|
| `qa-master`(위임 승인자) | 사람이 직접 모든 게이트 승인 |
| 대기 장부(AG-15) | 생략(사람이 직접 상태 확인) |
| 순찰 세션 | 생략 |
| 공유문서 루트 | 저장소 내 폴더, 또는 생략 |

안 갖췄다고 규칙이 깨지지 않는다. 그 자리를 **사람이 채운다는 선언**만 하면 된다.

## 세팅 — 네 걸음

### 1. 역할을 가른다

- 어느 세션이 **게이트웨이**인지, 어느 세션이 **실무자**인지 정한다.
- **게이트웨이 ≠ 실무자.** 같은 세션이 구현도 하고 자기 걸 승인하면 "자기 채점"이 된다 — 하네스가 막으려는 바로 그것이다. 구현은 **별도 실무자 세션**에 맡긴다.

### 2. 위임기록을 쓴다

- 게이트웨이에 위임한 것을 **글로 남긴다**(저장소 안 `위임기록.md`).
- 소규모 모드에서 위임 대상 = **코디네이션 역할뿐**이다: 실무자 세션 생성·종료, 사람 승인의 원문 전달, 상태 감시. **게이트 결정 권한은 위임하지 않는다.**
- 템플릿은 `design-notes/10-오케스트레이션-구성층.md` 부록 A.
- 규칙: **목록에 없는 건 전부 사람에게 올린다(화이트리스트).** 사람은 언제든 위임을 거둬들인다.

### 3. 실무자 세션을 띄운다

각 실무자 세션에 정할 것:

- **모델** · **권한 모드**(사람이 안 지켜보는 세션이 권한 프롬프트에 멈추지 않도록 미리 정한다. 단 권한 분류기를 우회하지는 않는다).
- **지시문 3줄**(공백이 세션을 멈춰 세우지 않게): ① 정본 근거(언급하는 값·명칭의 출처), ② 정본 도착 전 대기 중 행동(해도 되는 범위와 멈출 지점), ③ 막히면 문의처.
- **겹치지 않는 세션 이름.**
- 문의처(소규모 모드) = **사람, 또는 지시한 세션(게이트웨이)**. 세션이 사람에게 직접 묻는 창을 띄우는 대신, 지정한 창구에 질의하게 한다.

### 4. 굴린다

- 실무자는 **게이트에서 멈추고** 게이트웨이에 보낸 뒤 대기한다.
- 게이트웨이는 메시지를 받으면 깨어나 사람에게 올린다 → 사람이 결정 → 게이트웨이가 **원문 그대로** 실무자에 전달한다.
- 게이트웨이는 범위 밖 결정을 대신하지 않는다.

## 왜 안전한가

- 게이트웨이는 **위임기록에 적힌 것만** 한다. 게이트 승인은 전부 사람 몫이다.
- 범위 밖은 **전부 에스컬레이션.** 사람이 위임을 **언제든 번복**한다.
- 그래서 하네스의 사람 게이트가 세션이 여럿이어도 그대로 선다.

## 아직 안 넣은 것 (키울 때 더한다)

- **게이트 결정의 좁은 위임** — 게이트웨이가 일부 승인(예: 커밋 계획 승인)을 대신해 사람 부담을 더는 모드. 소규모 모드는 "전부 에스컬레이션"이 기본이다. 세션·작업이 커질 때 위임기록에 게이트 항목을 하나씩 더한다.
- **작업을 자동으로 나눠주는 엔진**(coordinator) — 소규모 모드는 사람이 작업을 나눈다.
- **장부·순찰.**

## 알아둘 것 (아직 검증 안 된 부분)

- **게이트웨이 깨움:** 살아있는(`/exit`로 끝내지 않은) 세션은 수신 메시지로 깨어난다 — 경험에서 나온 결론이고, 정밀 측정은 아직 아니다. 유휴 정리 시간("60분")은 **작업 편의상 잡은 약속값**이지 확인된 시스템 한계가 아니다.
- 이 모드는 **실전 검증 1회**에서 추려냈다. 내 환경에서 직접 돌려 쓸만한지·어디 상했는지 확인하며 고쳐 쓴다.
