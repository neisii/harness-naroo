# seosul-lint — 서술 규칙 린터 (읽기 전용)

한국어 문서의 **글투**를 점검한다. 세 가지를 찾는다:

- **번역투/과장 용어** — 사전(`번역투-교정사전.md`)에 오른 어색한 말. 자연스러운 대치어를 함께 보여준다.
- **이모지** — 텍스트 기호(✓ ✗ → ← · 등)는 빼고 실제 이모지만. (`⚠️`·`❤️`처럼 VS16 붙은 것도 잡음.)
- **시점 드리프트** — 2인칭 '당신'.

파일은 **읽기만** 한다. 고치지 않고, 어디를 어떻게 고칠지만 가리킨다. 승인·handshake 없이 아무 세션이나 호출할 수 있다.

## 실행

```sh
python3 "${CLAUDE_PLUGIN_ROOT}/skills/seosul-lint/seosul_lint.py" [경로 ...] [옵션]
```

| 옵션 | 의미 |
|---|---|
| `경로 ...` | 파일 또는 폴더(폴더는 하위까지 `*.md`). 생략하면 **현재 폴더 최상위 `*.md`** |
| `--dict <파일>` | 금칙어·대치어 사전. 생략하면 스킬에 번들된 `번역투-교정사전.md` |
| `--skip a.md,b.md` | 더 제외할 파일명(쉼표 구분). 사전 파일은 언제나 자동 제외 |
| `--json` | 구조화 JSON 출력(파싱용) |
| `--strict` | 위반이 하나라도 있으면 종료 코드 `1`(CI·pre-commit용). 기본은 보고만 하고 `0` |
| `--selftest` | 샘플로 탐지·오탐 방지 로직 자기 점검 |

## 사전 형식

사전 파일의 `## 사전` 아래 Markdown 표에서 읽는다. 행 형식:

```
| N | **용어** (설명) | 대안 | 메모 |
```

- 2번째 셀의 첫 **볼드**가 검색어다. 괄호 설명은 지우고 `/`·`·` 로 여러 검색어를 쪼갠다.
- 3번째 셀이 대안(출력에 ` → 대안`으로 붙는다).
- 번들 사전은 이 레포 `design-notes/번역투-교정사전.md`(정본)를 떠 담은 **배포용 사본**이다. 다른 규칙을 쓰려면 같은 형식의 사전을 만들어 `--dict`로 넘긴다.

## 매칭 규칙 (오탐을 줄이려는 설계)

- **2글자 이상 명사형**: 글자열이 그대로 들어 있으면 잡는다(`재조립`의 `조립`).
- **1글자 명사형**(예: `축`): 앞이 한글/영숫자가 아니고, 뒤가 한글이 아니거나 조사일 때만. → `축소`·`구축`·`수축`은 안 잡는다.
- **`~다` 동사형**(예: `박다`): 어간 + 활용 어미 꼴(`박는다`·`박았다`·`박아넣는다`). 어간이 1글자면 앞 경계도 요구해 `박스`·`박물관`은 제외.

## 알려진 한계

- 사전 기반이라 **사전에 없는 번역투는 못 잡는다.** 사람 검토를 대신하지 않는다.
- 부분문자열 오탐이 남을 수 있다(`부분배포`의 `분배`처럼). 보고는 사람이 걸러 읽는 것을 전제로 한다.
- 용어 사전·규칙의 뜻은 이 레포 `design-notes/08-서술규칙.md`(정본)와 `번역투-교정사전.md`에 있다.
