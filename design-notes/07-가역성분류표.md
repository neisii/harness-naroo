# 07 — 가역성 분류표

> **핵심 한 줄:** AI가 "이건 혼자 해도 될까, 사람한테 물어봐야 할까"를 스스로 정하는 기준 문서.
> 03(사람 병목·모아서 검수)의 "골라서 비동기로 넘기는 기준"과 02(멀티에이전트에 빠진 조각)의 "정보가 확실한 곳만 병렬화" 잣대를 하나로 모은 것.
> **정본.** 쉬운 설명은 지우지 않고 들여쓴 "쉬운 예로" 레이어로 함께 둔다.

---

## 결과 4가지 — 무엇을 할지

| 결과 | 뜻 |
|---|---|
| **A 자율 실행** | 그냥 한다 |
| **B 사후 검수** | 먼저 하고 → 장부에 남기고 → 사람이 나중에 모아서 본다(필요하면 되돌림) |
| **C 사전 승인** | 멈추고 사람 승인을 받는다 |
| **D 보류·질의** | 뭘 하란 건지 몰라 못 정함 → 옆으로 치우고 다른 일부터 (03의 제쳐-당김) |

> 쉬운 예로, 편의점 알바생이 할 수 있는 행동 4가지다(예시는 편의점 근무 경험이 있는 사용자가 들었다).
> - **그냥 하기**(사소하고 안전): 진열대 정리.
> - **하고 나서 말하기**(되돌릴 수 있는 일): 정식 가격표가 없는 상품에 임시 가격표를 뽑아 붙여 둔다. 손님이 보는 거라 영향은 남에게 가지만, 정식 가격표가 오면 바꿔 끼우면 된다.
> - **먼저 물어보기**(위험하거나 중요한 일): 단골손님이 외상을 해 달라고 한다. 안 갚으면 돈이 안 돌아오고(되돌릴 수 없음) 외상을 받을지는 가게 방침(사장님이 정할 일)이다. 받아 줬다가 안 갚으면 알바생이 물어내야 한다.
> - **일단 제쳐두기**(뭘 하란 건지 몰라 못 정하는 일): 점장님이 "거기 그거 좀 해 놔"라고만 하고 퇴근했다.
>
> 마지막이 중요하다 — 모르는 일에 멈춰서 사장님만 기다리면 아무것도 못 하니, 옆으로 치우고 다른 할 일을 먼저 한다.

## 기준 4가지 — 무엇을 보고 정하나

| 기준 | 질문 | 쉬운 예 |
|---|---|---|
| **① 가역성** | 잘못되면 되돌릴 수 있나? | 쏟은 물은 닦으면 됨 ↔ 깨진 유리컵은 못 붙임 |
| **② 기반 정보** | 뭘 하란 건지 확실한가? | "콜라 한 캔 갖다 줘" ↔ "거기 그거 좀" |
| **③ 영향 범위** | 나만 영향받나, 남도 받나? | 내 계산대만 ↔ 가게 전체 가격표 |
| **④ 업무 규칙** | 내가 정할 일인가, 사람이 정할 일인가? | 진열대 정리(내 일) ↔ 할인 몇 %(사장님 일) |

## 점수로 더하면 안 된다 — 거부권

가장 흔한 실수: "질문 4개에 점수 매겨 합치면 되겠네." **안 된다.** 딱 하나만 걸려도 **무조건 멈춰야 하는** 경우가 있기 때문이다.

> 쉬운 예로, 사장님이 "할인율 10%? 15%?" 고민 중인데 알바생이 그냥 15%로 가격표를 고쳐버렸다. 고치기 쉽고, 뭘 할진 확실하고, 내 일 같고 — 점수만 더하면 "안전하네, 그냥 해"가 나온다. 근데 **할인율은 사장님이 정할 일.** 알바생이 정하면 큰일이다.

그래서 **거부권**을 둔다 — 다른 기준이 아무리 안전해도 상쇄되지 않는, 무조건 멈추는 신호.

| 기준 | 유형 | 혼자 걸리면 |
|---|---|---|
| **④ 업무 규칙(사업 결정)** | 거부권 | → C (되돌릴 수 있어도) |
| **① 비가역(되돌릴 방법 없음)** | 거부권 | → C |
| **② 결정 못 할 만큼 모호** | 거부권 | → D |
| **③ 영향 범위** | 조절 | C로 밀되, 가역+명확이면 B+알림으로 완화 |

**③만 거부권이 없다.** 대신 분위기 조절용이다 — 남에게 영향 가지만 **되돌릴 수 있고 + 확실하면** 하고 나서 알려주기(B), 남에게 영향 가는데 **애매한 것도 겹치면** 먼저 물어보기(C).

## 확정된 규칙 4가지

1. **③ 영향 범위는 자동 판정.** 에이전트가 자기 구역(worktree + sparse로 받은 범위) 밖을 건드리면 → "이건 남한테 영향 가는 일"로 자동으로 본다.
2. **B(사후 검수)는 되돌릴 방법이 실제로 등록돼 있을 때만.** 말로만 "되돌릴 수 있어요"는 안 되고, 되돌리는 방법이 준비됐을 때만 혼자 한다. 없으면 자동 C.
3. **②·④는 스스로 판단하되, 기준별 값과 근거를 장부에 남긴다.** 혼자 정하긴 하는데 "왜 그렇게 봤는지"를 적어둔다. 그래야 사람이 나중에 보고 "이건 네가 정하면 안 됐는데"를 잡아낸다.
4. **자기 판단 확신이 낮으면 한 단계 더 보수적으로.** (나중에 보정 모델을 붙이면 더 정교해짐 — 01 Jev류, 속도 보조.)

## 길 정하는 순서 (STEP 1 → STEP 2)

나중에 이 규칙을 그대로 코드(라우터 스크립트)로 옮길 수 있도록, 순서를 명확하게 둔다.

```
STEP 1 — 거부권 먼저 (하나라도 걸리면 거기서 끝):
   ② 결정 못 할 만큼 모호?            → D
   ④ 사업 결정(사람 몫)?              → C
   ① 되돌릴 수 없음?                  → C

STEP 2 — 거부권 안 걸리면 ③으로 세부 조정:
   ③ 외부·공유 + 되돌릴 방법 미등록   → C (규칙 2)
   ③ 외부·공유 + (② 명확 & ① 가역)   → B + 알림
   ③ 외부·공유 + (주의 2개 이상)       → C
   ③ 내 구역                          → A(사소) / B(남길 값어치 있으면)

기본값: 애매하면 한 단계 더 보수적으로.
```

> **2026-11-21 정리:** 예전 STEP 1에는 "① 되돌릴 수 없음(또는 되돌릴 방법 미등록) → C"가 있어, 내 구역의 일도 되돌릴 방법이 없으면 C로 읽혔다. 확정 규칙 2와 스킬 구현(`reversibility_gate.py`)은 롤백 등록을 **외부·공유(B로 갈 일)에만** 요구한다. 내 구역의 일은 워크트리와 git이 되돌리는 수단이기 때문이다. 구현을 정본으로 보고 STEP 1에서 괄호를 빼고 STEP 2로 옮겼다(사용자 결정).

## 판정 근거 기록 (AG-15 호환, 독립)

B·C·D로 갔거나 혼자 판단한(A) 자리는 아래 한 조각을 남긴다. 사람이 나중에 **모아서** "이건 네가 정하면 안 됐는데"를 잡아내는 근거다(규칙 3).

**AG-15 호환이되 장부에 안 묶인다.** 장부(대기 현황)를 쓰는 사람은 이 조각을 그대로 장부에 넣어 순찰·검수 흐름에 띄울 수 있고(pending-status-check·qa-inbox가 집계), 장부를 안 쓰는 사람은 그냥 JSON 파일로만 남겨도 된다. 라우팅 판정 자체는 장부가 전혀 필요 없다 — 그래서 결합을 느슨하게 둔다.

```json
{
  "종류": "가역성판정",
  "작업": "무슨 일인지 한 줄",
  "결과": "A | B | C | D",
  "판정시각": "YYYY-MM-DD HH:MM",
  "세션": "판정한 세션명",
  "기준": {
    "가역성":   {"값": "가역 | 비가역", "롤백경로": "있음 | 없음", "근거": "..."},
    "기반정보": {"값": "명확 | 모호", "근거": "..."},
    "영향범위": {"값": "내구역 | 외부공유", "판정방식": "자동(worktree·sparse) | 자가", "근거": "..."},
    "업무규칙": {"값": "해당없음 | 사업결정", "근거": "..."}
  },
  "확신도": "높음 | 보통 | 낮음",
  "거부권발동": "① | ② | ④ | 없음",
  "보수조정": true
}
```

| 필드 | 뜻 |
|---|---|
| `결과` | 최종으로 고른 A/B/C/D |
| `기준.*.값` | 네 기준을 각각 어떻게 봤는지(self-assess) |
| `기준.*.근거` | **왜 그렇게 봤는지** — 사후 적발의 핵심. 비면 안 됨 |
| `영향범위.판정방식` | ③을 worktree·sparse로 자동 판정했는지, 자가 판단했는지 |
| `확신도` | 낮으면 규칙 4로 한 단계 보수적으로 간 뒤 그 사실을 남김 |
| `거부권발동` | STEP 1에서 무엇이 걸려 멈췄는지(없으면 STEP 2로 갔다는 뜻) |

## 한 줄 요약

> 되돌릴 수 있고, 확실하고, 내 일이면 → 혼자 한다.
> 못 되돌리거나, 모르거나, 사람이 정할 일이면 → 멈추고 물어본다.
> 이 중 "무조건 물어봐야 하는 것"은 점수가 높아도 덮어놓고 지나가지 않는다.
