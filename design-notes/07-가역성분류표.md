# 07 — 가역성 분류표 (쉬운 버전)

> **핵심 한 줄:** AI가 "이건 혼자 해도 될까, 사장님한테 물어봐야 할까?"를 스스로 정하게 해주는 규칙표.
> 문서 03(사람 병목)의 "선택적 비동기 게이트"와 문서 02(기반정보 완전성)의 공통 기준을 하나로 모은 것.
> 이 문서는 **중학생도 이해할 수 있게** 쓴 버전이다. 정식 라우팅 규칙은 맨 아래 "부록"에 요약.

---

## 이 표가 하는 일

AI를 **편의점 알바생**이라고 생각해 보자. 일을 하다 보면 이런 고민이 생긴다.

> "이건 내가 그냥 해도 될까? 아니면 사장님한테 먼저 물어봐야 할까?"

이 표는 **그걸 정해주는 규칙표**다. 알바생(AI)이 매번 헷갈리지 않게.
(회사=Orca, 직원=내 하네스 비유와도 통한다 — 문서 01.)

## 알바생이 할 수 있는 4가지 행동

| 행동 | 언제 |
|---|---|
| **그냥 하기** | 아주 사소하고 안전한 일 |
| **하고 나서 말하기** | 되돌릴 수 있는 일 (먼저 하고 나중에 "이거 했어요" 보고) |
| **먼저 물어보기** | 위험하거나 중요한 일 (하기 전에 허락) |
| **일단 제쳐두기** | 뭘 하란 건지 몰라서 못 정하는 일 (옆으로 치우고 **다른 일부터**) |

마지막이 중요하다. 모르는 일에 멈춰서 사장님만 기다리면 **아무것도 못 한다.**
그래서 그건 옆으로 치워두고 **다른 할 일을 먼저** 한다. (문서 03의 "제쳐-당김".)

## 알바생이 스스로 던지는 4가지 질문

1. **"이거 잘못되면 되돌릴 수 있나?"**
   쏟은 물은 닦으면 됨(쉬움) ↔ 깨진 유리컵은 못 붙임(불가)
2. **"뭘 하라는 건지 확실한가?"**
   "콜라 한 캔 갖다 줘"(확실) ↔ "거기 그거 좀"(뭐요…?)
3. **"나만 영향받나, 남도 영향받나?"**
   내 계산대만(나만) ↔ 가게 전체 가격표 바꾸기(남도)
4. **"이건 내가 정할 일인가, 사장님이 정할 일인가?"**
   진열대 정리(내 일) ↔ **"할인 몇 %로 할까"(사장님 일!)**

## 제일 중요한 비밀: 점수를 더하면 안 된다

많은 사람이 "질문 4개에 점수 매겨 합치면 되겠네?" 하고 실수한다. **안 된다.**
**딱 하나만 걸려도 무조건 물어봐야 하는** 경우가 있기 때문이다.

**예시:**
> 사장님이 "할인율 10%? 15%?" 고민 중인데, 알바생이 그냥 **15%로 가격표를 고쳐버렸다.**
> - 고치기 쉽고(✓), 뭘 할진 확실하고(✓), 내 일 같고(✓)…
> - 점수만 더하면 **"안전하네? 그냥 해!"** 가 나온다.
> - 근데 **할인율은 사장님이 정할 일.** 알바생이 정하면 큰일!

그래서 규칙:
> **질문 4번("내가 정할 일인가?")에 걸리면, 나머지가 아무리 안전해도 무조건 "먼저 물어보기".**
> 이걸 **"거부권"**이라 부른다 — 다른 걸로 못 덮는, 무조건 멈추는 신호.

**거부권을 가진 질문 3개:**
- **"내가 정할 일 아님(사장님 몫)"** → 무조건 물어봐
- **"되돌릴 수 없음"** → 무조건 물어봐 (못 되돌리는 걸 "하고 나서 말하기"는 너무 위험)
- **"뭘 하란 건지 모름"** → 무조건 제쳐두고 물어봐

**딱 하나, 3번("남도 영향받나?")만** 거부권이 없다. 대신 **분위기 조절용**이다:
- 남에게 영향 가지만 **되돌릴 수 있고 + 확실하면** → 하고 나서 "이거 바꿨어요" **알려주기**
- 남에게 영향 가는데 **애매한 것도 겹치면** → 그냥 먼저 물어보기

## 우리가 정한 규칙 3가지 (쉽게)

1. **"나만 영향받나?"는 자동으로 판단한다.**
   알바생이 자기 구역(맡은 칸) 밖을 건드리면 → "이건 남한테 영향 가는 거구나"를 **자동으로 알아챔.**
2. **"되돌리는 방법"이 없으면 무조건 물어본다.**
   "하고 나서 말하기"를 하려면 **되돌리는 방법이 진짜로 있어야** 한다. 말만으론 안 되고,
   **실제로 되돌릴 방법이 준비됐을 때만** 혼자 한다.
3. **알바생이 스스로 판단하되, 이유를 적어둔다.**
   혼자 정하긴 하는데 **"왜 그렇게 생각했는지 공책에 적어둔다."** 그래야 나중에 사장님이 공책을 보고
   **"어? 이건 네가 정하면 안 되는 거였는데!"** 하고 **잘못을 잡아낼 수 있다.**

## 한 줄 요약

> **되돌릴 수 있고, 확실하고, 내 일이면 → 혼자 한다.**
> **못 되돌리거나, 모르거나, 사장님이 정할 일이면 → 멈추고 물어본다.**
> **이 중 "무조건 물어봐야 하는 것"은 점수로 못 덮는다.**

## 부록 — 정식 라우팅 요약 (어른용)

**4가지 결과:** A 자율 실행 / B 사후감사(하고→장부 기록→비동기 검토·롤백) /
C 사전승인(멈추고 사람 승인) / D 보류·질의(제쳐-당김).

**4가지 기준:** ① 가역성 ② 기반정보 완전성 ③ 영향범위 ④ 업무규칙 연관.

**가중치 = 거부권 기준 + 조절 기준 (점수 합산 ✗, 상쇄 불가).**

| 기준 | 유형 | 단독 red 효과 |
|---|---|---|
| ④ 업무규칙 | 거부권 | → C (되돌릴 수 있어도) |
| ① 비가역/롤백경로 없음 | 거부권 | → C |
| ② 결정불가 모호 | 거부권 | → D |
| ③ 영향범위 | 조절 | C로 밀되, 가역+명확이면 B+통지로 완화 |

```
STEP 1 (거부권 — 걸리면 그 바닥 확정):
   ② 결정불가?      → D
   ④ 사업 결정?     → C
   ① 비가역/롤백없음 → C
STEP 2 (거부권 없으면 ③로 미세조정):
   ③ 외부·공유 + (②명확 & ①가역)   → B + 통지
   ③ 외부·공유 + (주의 2개 이상)     → C
   ③ 내 레인                        → A(사소) / B(흔적가치)
기본값: 애매하면 한 단계 보수적으로.
```

**확정된 설계 결정 (1차 검토):**
- ③ 영향범위 = **worktree + sparse-checkout 범위로 자동 판정**
- B는 **등록된 롤백 경로가 있을 때만** — 없으면 자동 C
- ②·④는 **에이전트 self-assess + 기준별 점수·근거를 장부에 기록**(사후 적발용)
- 자기평가 확신도 낮음 → 한 단계 보수적 (미래: 보정모델 Jev류, 문서 01)
