- 대상: 관문 1·2를 통과한 커밋(`6e34432`). 마켓이 로컬 폴더라 이 PC의 저장소 폴더가 그대로 설치본이다.
- 저장소: `neisii/gate3-trial`(공개, 2026-11-21 사용자 결정). 시험을 못 통과해도 그대로 공개한다(사용자 동의) — 실전 예제가 된다. main 브랜치 보호(PR 필수·강제 push·삭제 금지·관리자 포함), 기밀 게이트·귀속 줄 훅 복사 설치, Apache-2.0 + `NOTICE`.
