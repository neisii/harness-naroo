# 번역투 교정 사전 (AI 어투 → 자연스러운 한국어)

> **목적:** AI(나)가 자주 쓰는, **한국인에게 어색하거나 과장된 표현**을 자연스러운 말로 바꾼다(과장 축소 포함).
> T1(문서 08)과 다른 갈래 — 저건 **난이도**(어려움↔쉬움), 이건 **자연스러움**(번역투↔한국어).
> **자라는 사전:** 걸릴 때마다 한 줄씩 추가한다. (backlog T2)

---

## T1(용어 대치)과 뭐가 다른가

| | T1 — 용어 대치 (문서 08) | 이것 — 번역투 교정 |
|---|---|---|
| 판정 기준 | **난이도** (어려운 전문어인가) | **자연스러움** (번역투·과용인가) |
| 예 | `cherry-pick` = 어렵지만 공용어 → **유지** | `축` = 안 어렵지만 "axis" 직역투 → **교정** |
| 사전 | 어려운 용어 → 쉬운 말 | AI 어투 → 자연스러운 한국어 |

> 한 표현이 **둘 다** 걸릴 수 있다(겹침 OK). 하지만 **필터가 다르므로 사전은 따로** 둔다.

## 쓰는 법 (제안)

1. 어색한 표현이 걸리면 **아래 표에 한 줄 추가**(원래 → 대안 + 맥락 메모).
2. 글을 내보내기 전 이 사전으로 **자기 점검**(원칙 0의 연장: "내가 쓴 어투가 자연스러운가").
3. **맥락 의존**은 "항상 바꿈"이 아니라 **"제안 후 확인"** — 예: `축`은 보통 "기준"이지만 양 끝을 가리키면 "방향".
4. **과잉 순화 금지(적재적소, 원칙 1).** 번역투 교정 ≠ "외래어 전부 순우리말化". 흔한 외래어가 더 자연스러우면 그대로 둔다
   (예: "묶음/꾸러미" 억지로 붙이지 않기). 어색한 것만 바꾼다.

"나머지 기준이 괜찮아도 걸린 하나를 덮지 못한다"는 영어 outweigh·override를 옮긴 말이라 "무엇을 덮나" 하고 걸린다. 한국어 "덮어 놓다"는 ① 문제를 해결하지 않고 외면함 ② 따지지 않고 무조건 함(덮어놓고)이라는 뜻이 살아 있으니, 그 뜻을 살려 "덮어놓고 지나가지 않는다"로 쓴다. **린터 금칙어에서 뺌:** "뚜껑을 덮다"·"덮어쓰기" 등 자연스러운 쓰임이 많다. |
| 34 | 서다·섰다 (규율·게이트·구조가 hold·stand 직역) — 린터 금칙어 아님 | 맥락 따라 **지켜지다**(규율·규칙) / **작동하다**(게이트·장치) / **갖춰지다**(구조·뼈대) / **들어가다**(절차) / **나오다**(답) | 2026-11-20 사용자 지적. "규율이 섰다", "게이트가 그대로 선다"는 영어 the discipline held·the gate stands를 옮긴 말이라 무엇이 어떻게 됐는지 흐리다. 실제로 일어난 일을 말한다 — 규율이면 "지켜졌다", 게이트면 "작동했다". **린터 금칙어에서 뺌:** "줄을 서다"·"계획이 서다"처럼 자연스러운 쓰임이 많다. |
| 35 | 돌다·돌리다 (코드·테스트·세션을 run 직역) — 린터 금칙어 아님 | 맥락 따라 **실행하다**(코드·스크립트) / **테스트하다**(테스트) / **동작하다**("코드가 돈다"→"동작한다") / 띄우다·쓰다(세션) | 2026-11-20 사용자 지적. "합친 모양은 아무도 안 돌렸다"에서 걸림. 개발자 입말로는 흔하지만, 초심자용 글에서는 무엇을 했는지(실행·테스트)가 흐려진다. 하는 일을 그대로 말한다. **린터 금칙어에서 뺌:** "되돌리다"·"돌려주다"·"눈을 돌리다"와 글자가 겹쳐 오탐이 많다. |
| 36 | 모양 (shape·configuration 직역, 코드·결과의 상태를 가리킬 때) — 린터 금칙어 아님 | 맥락 따라 **병합한 코드·결과**(합친 뒤의 코드) / **조합**(골라 묶은 것) / **경우**("흔한 모양은"→"흔한 경우는") | 2026-11-20 사용자 지적. "합친 모양", "내보낼 모양 그대로"는 영어 shape·configuration을 옮긴 말이라 무엇을 가리키는지 흐리다. 가리키는 대상을 그대로 쓴다. **린터 금칙어에서 뺌:** 생김새를 말하는 자연스러운 "모양"이 많다. |
